# 증여세 계산기 (gift-tax)

상증세법 기준 증여세·증여재산가액 통합 계산기 — 서버 없이 동작하는 단일 HTML 앱.

- 증여세 계산: 10년 재차증여 합산 · 증여재산공제 · 세대생략 할증 · 신고세액공제 · 가산세 · 연부연납
- 증여재산가액 산정: §35 저가·고가양도 / §41의4 금전무상대부 / §42 임대용역 / §37 무상사용 / §39 불균등 증자·감자 / §45의5 특정법인 거래
- 모든 계산은 원 단위 정수. 산정 결과는 각 탭에서 증여세 계산 탭으로 자동 연동.

아이폰에서 앱처럼 쓰기: Safari로 열기 → 공유 → **홈 화면에 추가**.

`index.html`은 빌더가 생성한 산출물입니다. 개인 실무 보조용이며, 결과는 법령·사실관계 확인 후 사용하세요.
